## 📌 Convención de Commits

En este proyecto seguimos la convención de [Conventional Commits](https://www.conventionalcommits.org/) combinada con [Gitmoji](https://gitmoji.dev/) para mantener un historial de cambios claro, legible y estandarizado.

### 📝 Estructura del Mensaje

```bash
<icono> <tipo>(<alcance_opcional>): <descripción concisa en imperativo/inglés o español>
```

### 🎨 Tipos de Commits y Emojis

| Icono | Tipo | Descripción | Ejemplo |
| :---: | :--- | :--- | :--- |
| ✨ | `feat` | Nueva característica, componente o vista | `✨ feat(ui): add dark mode toggle` |
| 🐛 | `fix` | Corrección de un error o bug | `🐛 fix(cart): prevent negative item quantity` |
| 💄 | `style` | Cambios de diseño, CSS, estilos o ajustes visuales | `💄 style(navbar): adjust padding and mobile shadow` |
| ♻️ | `refactor` | Refactorización de código sin alterar su funcionamiento | `♻️ refactor(hooks): simplify fetch wrapper` |
| ⚡️ | `perf` | Mejoras de rendimiento o reducción de tiempos de carga | `⚡️ perf(images): convert home banners to webp` |
| 📝 | `docs` | Cambios exclusivamente en documentación o comentarios | `📝 docs: update setup instructions in README` |
| 🧪 | `test` | Adición o corrección de pruebas unitarias o E2E | `🧪 test(auth): add unit test for token validation` |
| 🔧 | `chore` | Tareas de mantenimiento, dependencias o configuración | `🔧 chore: bump dependencies version` |
| 🚀 | `deploy` | Despliegue, configuración de hosting o producción | `🚀 deploy: update vercel deployment config` |
| 👷 | `ci` | Modificaciones en pipelines, GitHub Actions o flujos CI/CD | `👷 ci: setup github workflow for lint check` |
| 🔒️ | `security` | Parches de seguridad o tratamiento de vulnerabilidades | `🔒️ security: sanitize user inputs against xss` |
| 🌐 | `i18n` | Soporte multiidioma, traducción o localización | `🌐 i18n: add spanish locale dictionaries` |
